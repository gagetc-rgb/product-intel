# BigSpy pass, 2026-11-10 (free plan, owner's login, in-app browser)

Filters: Facebook, industry eCom, Time = Last 2 Years (2024-11-10 → 2026-11-10), Exact Search on, **all countries** (the US filter was set but never applied: the quota ran out first), sort = relevance, view = Advertisers (one ad shown per advertiser). The free plan shows 5 pages × 20 advertisers. Page names and domains are masked (`try***.com`).

Raw rows: `persimmon_soap_advertisers_2026-11-10.tsv` (96 advertisers, 75 named + 21 "Special Creative"), `tallow_balm_advertisers_2026-11-10.tsv` (40).

Quota: date preset + 2 keyword searches + Advertisers view + ~8 page turns + country and sort changes, then "Today's search quota has been used up". Page turns seem not to count; filter changes do.

Limits: relevance sort favours recent ads, so the shown ad's start date is not the advertiser's start; masked domains stop us from merging pages into stores (one store can run many persona pages); all countries, not the US.
